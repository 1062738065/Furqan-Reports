# نظام توثيق الأداء — النسخة البسيطة (HTML/CSS/JS بدون أدوات بناء)

هذه بداية إعادة بناء الموقع بنفس أسلوب نظام المقاصف: ملفات تفتحينها وتعدّلين فيها مباشرة، بدون npm أو أي خطوة بناء.

## الملفات (حتى الآن)
- `index.html` — صفحة تسجيل الدخول
- `dashboard.html` — لوحة تحكم المديرة: لوحة معلومات + عرض الأقسام والوحدات + إدارة الأقسام والوحدات (إضافة/تعطيل)
- `config.js` — الاتصال بجدول Google Sheets (نفس الجدول والرابط المستخدم حاليًا)
- `logo-config.js` — شعار الجمعية
- `style.css` — التنسيق العام (نفس ألوان النسخة الحالية)
- `Code.gs` — نفس الخلفية المستخدمة حاليًا (لا تحتاجين تعيدين نشرها، هي نفسها)

## ملاحظة مهمة
نفس مفاتيح البيانات المستخدمة في الموقع الحالي (React) مستخدمة هنا بالضبط، فأي أقسام/وحدات محفوظة سابقًا بجدولك تظهر مباشرة هنا بدون أي تحويل.

## كيف تجربينها
افتحي `index.html` مباشرة في المتصفح (بدون رفع لأي مكان)، أو ارفعي المجلد كامل على GitHub Pages بنفس طريقة نظام المقاصف. سجّلي دخول بحساب المديرة (admin) الموجود في ورقة "المستخدمون".

## الباقي (لم يُبنَ بعد — ينتظر رأيك بعد المراجعة)
- صفحة الوحدة (unit.html) لتعبئة التقرير بأقسامه الـ15
- إدارة مؤشرات الأداء وإدارة الأهداف (حاليًا "قيد الإنشاء")
- عرض التقرير الكامل ومعاينته للطباعة
- مسار المراجعة والاعتماد
